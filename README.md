# Python Web 3 — Estudos com Flask

Repositório de estudos de desenvolvimento web com **Python e Flask**. Reúne exemplos e atividades feitos durante a disciplina, desde a criação de rotas até aplicações com persistência de dados.

## O que estou praticando

- Criação de aplicações web com Flask.
- Organização de rotas, controllers e models.
- Renderização de páginas com templates.
- Integração com banco de dados MySQL.
- Operações CRUD.
- Autenticação e funcionalidades relacionadas a login.
- Integração com APIs.

## Projetos e atividades

O repositório contém pastas de aulas e exemplos independentes, incluindo:

- Introdução ao Flask.
- CRUD com MySQL.
- Integração com APIs.
- Login e segurança.
- Aplicação de galeria.

## Tecnologias identificadas

- Python
- Flask
- Flask-SQLAlchemy
- PyMySQL
- MySQL
- HTML e templates Jinja

## Como utilizar

As atividades são projetos separados. Entre na pasta da atividade desejada, confira os arquivos e eventuais dependências específicos e execute a aplicação conforme sua configuração.

> Repositório acadêmico em evolução. As atividades têm finalidade didática e não devem ser consideradas automaticamente prontas para produção.
